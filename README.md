# 자활 도구 모음 (안내 페이지)

다섯 도구(업무 도구·지침 찾기·국기초 가늠표·자활은 처음이지·참여자 길잡이)를 한 주소로 안내하는 페이지.
위는 3D 「굿균의 자활 사무실」(누르면 굿균이 걸어가 안내), 아래는 카드 목록·공유 단추(주소 복사·안내 글 복사·QR).

## 파일
- `index.html` — 화면(카드는 tools.js로 그림)
- `tools.js` — **도구 목록. 새 도구는 여기에만 넣으면 카드·3D 사무실·번호 단추·개수 글자가 함께 바뀜**
- `office3d.js` — 3D 사무실(three.js r128, cdnjs). WebGL이 안 되면 카드만 보임
- `img/*.webp` — 3D 굿균 그림(힉스필드 GPT Image 2.6으로 원래 굿균을 본떠 만듦, 2026-11-09): hello(인사)·walk(걷기)·tools·search·gukgicho·start·guide

## 새 도구 넣는 법
1. `tools.js` 목록 끝에 `{ … }` 하나를 복사해 붙이고 글·주소를 바꾼다.
2. `spot`: desk 책상 · shelf 책장 · table 상담 탁자 · board 칠판 · counter 안내 데스크 · kiosk 세움 화면(안 쓰면 kiosk).
   색(`color`)은 물건·고리·이름표에 함께 쓰임.
3. `pic`: 굿균 그림 이름. 새 모습이 필요하면 힉스필드에서 `img/hello.webp`를 본보기로 같은 화풍으로 만들고
   배경 투명·발끝을 아래에 맞춰 512×460 webp로 `img/`에 넣는다(없으면 hello).
4. 자리는 들어온 순서대로 8곳까지 자동(`office3d.js`의 SLOTS). 9개째부터는 카드에만 나옴 → 그때 SLOTS를 늘리거나 방을 넓힌다.
5. 주소 끝 `#s1`~`#s8`이면 그 자리에서 시작(한 도구만 알릴 때).

## 확인하는 법
`python -m http.server 8790` 뒤 http://127.0.0.1:8790/ (파일로 바로 열면 그림을 못 읽음)
